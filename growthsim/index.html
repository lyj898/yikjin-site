How this was built

The problem. A single projected number — "your money grows to $X" — doesn't build intuition for how compounding actually works. Most of the growth in a long time horizon comes from interest earning interest, not from the contributions themselves, and that's hard to feel without seeing the shape of the curve and watching it respond as assumptions change.

The key decision. The math lives in calc.js, a pure function that takes a plain inputs object and returns a plain array of yearly results — no DOM, no rendering, no side effects. app.js owns everything about state, sliders, and the chart. That separation means the engine can be reasoned about (or unit-tested) independently of the UI, and the UI can be redesigned without touching the math.

The hard part. Getting the chart to feel instant while dragging a slider, without either lagging or flickering. Inputs are batched with requestAnimationFrame so a burst of slider events collapses into one recalculation per frame, and the chart updates by mutating its existing dataset arrays rather than being destroyed and recreated — Chart.js then animates between the old and new shape instead of a hard cut.

What I'd improve. The current model projects a single deterministic path from a fixed rate (or fixed rate bands). A more honest picture of investing risk would run a Monte Carlo simulation across a distribution of return sequences and show a range — a median path plus a spread — rather than one line implying certainty it doesn't have.

About this tool

GrowthSim projects growth using standard compound interest: at each compounding period, interest is calculated on the current balance and added to it, then the period's contribution is added. Monthly contributions are converted to match whichever compounding frequency is selected. Inflation-adjusted figures deflate each year's nominal contributions and balance by the cumulative inflation rate, expressing results in today's purchasing power. This tool is for illustrative purposes only — it does not account for fees, taxes, or real-world market volatility, and is not investment advice.
